## 二、时长与帧对齐

时间轴不是先定时长再往里塞内容，而是**按旁白实测长度倒推**：

```
句起点     = 场景起点 + 0.8（前导）
句终点     = 句起点 + 该句旁白实测时长
下一句起点 = 句终点 + 0.30（句间留白）
场景时长   = 0.8 + Σ句时长 + 0.30 ×（句数 − 1）+ 0.4（收尾）
场景时长向上取 0.5 秒倍数
总时长     = 片头 6.0 + Σ场景 + 片尾 9.0
```

因此每句话的字幕起止就是它自己的语音起止，观众的「听到」与「看到」严格同步。

帧对齐校验：

```
totalFrames = round(120.00 × 60) = 7200
duration    = 7200 / 60 = 120.00 s
120.00 是 0.5 的整数倍  ✓
```

时长写在四处，必须始终一致：

| 位置 | 值 |
| --- | --- |
| 本文件「总览」与「场景总表」 | 120.00 |
| `js/timeline.js` → `duration` | 120.0 |
| `index.html` → `data-cf-duration` | 120 |
| 运行时 `window.VIDEO.duration` | 120 |

## 六、旁白生成说明

旁白不是手录，是用用户指定的参考音色做 AI 语音克隆，逐句生成后按时间轴拼接。

| 项 | 说明 |
| --- | --- |
| 引擎 | MOSS-TTS-Nano（本地推理，CPU） |
| 模式 | `voice_clone`（只用参考音频，不接受参考文字稿） |
| 参考音色 | 用户提供的单声道样本，约 21 s，普通语气 |
| 生成方式 | 34 句**逐句**生成，同一进程内只加载模型一次，每句固定 seed 保证可复现 |
| 切分理由 | 整段生成时长不可控、句间断句会漂移；逐句生成才能让字幕与语音严格对齐 |
| 后处理 | 每句裁掉首尾静音（阈值 −45 dBFS，前后各留 60 ms 气口） |
| 拼接 | 按上表起点放入 120 s 音轨，未做时间拉伸，语音保持原始速度 |
| 输出 | `resource/audio/voice/voice_01.wav`，48 kHz 立体声，120.000 s |

语速实测：平均约 4.2 汉字/秒（最快 5.5、最慢 3.3），略慢于原计划的 4.5，属于平静叙述节奏。

## 八、偏离规范记录

| 项 | 规范要求 | 实际 | 原因 |
| --- | --- | --- | --- |
| 背景色 | 禁止纯黑 #000 | 使用 #000000 | 用户明确要求「背景使用纯黑背景」，按优先级「用户当前对话指令 > 其余章节」执行 |
| 片头信息 | 可含技术规格行 | 无分辨率 / 帧率 / 时长行 | 用户要求「开头不要写分辨率这些，把它当成一个真正的视频」 |
| 时长 | 建议 30–180 s | 120.0 s | 在范围内 |
| 字幕单条下限 | 1.2 s | 第 17、31 句旁白短于 1.2 s，字幕延长至 1.2 s | 优先保证字幕可读 |
| 时长基准 | 按字数公式估算 | 按旁白实测时长倒推 | 有真实旁白后，时长应以语音为准，否则字幕与语音必然错位 |
