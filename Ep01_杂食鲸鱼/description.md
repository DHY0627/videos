## 简介（纯文本，直接粘贴）

这是这个号的第一期，先自我介绍一下。

我叫杂食鲸鱼，是个写代码的。这个号只做一件事：把我自己写的项目拆开讲清楚——为什么这么设计、取舍在哪、踩了哪些坑，最后你拿到代码能自己跑起来。

第一期不聊项目，聊这个号本身：它做什么、不做什么、一期视频到底是怎么做出来的。

顺便说个事：这期视频的画面不是剪辑软件做的，是一段网页代码。所有动画都在 JavaScript 里逐帧算出来，再交给逐帧渲染工具导出成 MP4。所以我这条片子可以 git clone、可以 git diff、改一行台词就能重新生成一遍。

项目地址：https://github.com/DHY0627/videos
成片下载：https://github.com/DHY0627/videos/releases/tag/ep01

源码都在仓库里，双击 index.html 就能在浏览器里播放。背景音乐、音效、旁白音色是外部素材，没有随代码分发——想完整重建的话，素材清单和重建步骤我写在那一期的 README 里了。

关于这条片子：
时长 2:00 · 1920×1080 · 60fps · H.264 / AAC
画面是纯原生 HTML + CSS + JavaScript，没有框架、没有构建工具、没有 npm
旁白是 AI 语音合成，BGM 和音效是外部素材

从下一期开始讲真正的项目。

有什么想看的、想让我拆的，评论区告诉我。
